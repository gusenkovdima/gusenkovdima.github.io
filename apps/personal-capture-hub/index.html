Personal Capture Hub

Personal Capture Hub is a private Telegram-based capture and routing assistant operated for a single owner. It collects short notes and operational records and can export approved data into owner-controlled storage.

Google Drive access

The app uses Google Drive only after the owner grants OAuth consent. Drive access is used for:

  • exporting capture batches;
  • publishing routing queue and approved routing artifacts;
  • storing verified off-site backups created by the app's backup workflow.

Who can use it

The production bot is restricted to an allowlisted owner account. There is no public registration or third-party user service.

Data handling

Google Drive data is used only to provide the application's storage, export, routing and backup functionality. It is not sold, used for advertising, or shared for unrelated purposes.

See the Privacy Policy for the general data-handling rules used by these personal apps.
